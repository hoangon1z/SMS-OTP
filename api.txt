4. Lấy số điện thoại để nhận code
Phương thức: GET
URL: https://apisim.codesim.net/sim/get_sim?service_id=1&api_key=eyJhbGciOiJIUzUxMiJ9.eyJzdWIiOiJob2FuZ3RrcHJvMDExIiwianRpIjoiNjA3NzYiLCJpYXQiOjE3MjYxNzQ3NDMsImV4cCI6MTc4ODM4Mjc0M30.PFCOZx56TCeI1Go23o0LVecGad9p4r0aHjq1NjkE6jd0KoTCrG-R7gO-th5BxZnVzo9mGgMgvwDQUSjdq55XMw
Tham số bắt buộc phải có:
- api_key: API key của tài khoản
- service_id: Id của dịch vụ được lấy theo api lấy danh sách dịch vụ ở trên
Tham số không bắt buộc:
- phone: Tùy chọn đầu số muốn lấy
